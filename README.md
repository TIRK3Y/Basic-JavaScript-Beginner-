# Basic JavaScript (Beginner)

A collection of small JavaScript exercises, written while learning the basics of the language in a full-stack web development course. Each file is a standalone snippet that covers one concept, such as string handling, conditionals, functions, arrays or loops.

## Contents

| File | Description |
| ---- | ----------- |
| `99Bottles.js` | Prints the "99 Bottles of Beer" lyrics using a `while` loop |
| `BMI_Calculator.js` | Calculates a body mass index from weight and height and rounds it |
| `buyingLunch.js` | Picks a random name from an array to pay for lunch |
| `Caps.js` | Prompts for a name and capitalizes the first letter |
| `dogageconverter.js` | Converts a dog's age to human years |
| `fitBuzz.js` | FizzBuzz that appends the next value to an array on each call |
| `functions.js` | Introductory function that logs a sequence of steps |
| `guestList.js` | Checks whether a name is on a guest list array |
| `ifElse.js` | Love-score calculator using `if`/`else` |
| `index.js` | Tweet character counter (140-character limit) |
| `leapYear.js` | Works out whether a year is a leap year |
| `LifeInWeeks.js` | Calculates the days, weeks and months left until age 90 |
| `loveCalculator.js` | Random love-score generator |
| `string.js` | Basic string method example |
| `tweet.js` | Truncates input to 140 characters |
| `fibonacci.js` | Placeholder (currently empty) |

## Tech stack

- JavaScript (ES5 syntax)

## Running the snippets

Several files use the browser-only `prompt()` and `alert()` functions, so run them in a browser's developer console by pasting the file contents into the Console tab. Files that use only `console.log` and pure functions, such as `99Bottles.js`, `BMI_Calculator.js` and `LifeInWeeks.js`, also run with Node.js:

```bash
node 99Bottles.js
```

Some files, such as `buyingLunch.js`, `leapYear.js` and `fitBuzz.js`, only define functions. To see output, call the function from the console, for example `isLeap(2024)`.
